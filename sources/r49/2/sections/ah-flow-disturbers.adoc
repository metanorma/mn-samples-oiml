== Flow disturbers

=== General

<<figure-h-1>> to <<figure-h-12>> show flow disturber types to be used in tests
as specified in <<scls-7-10>>.

NOTE: All dimensions shown in the drawings are in millimetres, unless otherwise
stated.

Machined dimensions shall have a tolerance of stem:[pm 0.25 "unitsml(mm)"] unless
otherwise stated.
