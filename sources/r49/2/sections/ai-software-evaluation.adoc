== Software evaluation for software-controlled water meters

The software evaluation procedure concerns an evaluation of compliance with
the requirements as described in <<ISO_4064_1_2024,annex=D>>|<<OIML_R_49_1_2024,annex=D>>, and comprises
a combination of analysis and validation methods and tests as shown in <<table-i-1>>.
The explanation of the abbreviations used and the relation to the methods as
described in detail in <<OIML_D_31_2023>> is shown in <<table-i-2>>.
