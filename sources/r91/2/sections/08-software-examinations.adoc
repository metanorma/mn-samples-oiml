
== Software examinations

Software examinations are performed according to documentation review and functional
observation of the EUT.

NOTE: National regulations may require higher levels for the validation and
examination steps.

=== Software evaluation methods

Evaluation methods for software requirements are defined in <<OIML_D_31_2023,clause=7>>.

=== Software examination level

The speed meter software requirements shall be examined according to the Examination
level A (<<OIML_D_31_2023>> – normal examination level).
