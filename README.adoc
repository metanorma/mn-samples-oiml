= OIML Metanorma Documents

These documents belong to the Organisation Internationale de Métrologie Légale /
International Organization of Legal Metrology (OIML).

This repository contains the OIML R060 recommendation and its parts.

Published components are available here:

* https://metanorma.github.io/mn-samples-oiml/[OIML R 60 - Metrological regulation for load cells (Edition 2021)]

== Structure

`sources/`::
Source of the documents.

`sources/r060/`::
OIML R060: Metrological regulation for load cells

`sources/r060/collection.yaml`::
Metanorma collection of all OIML R060 parts.

`sources/r060/1/`::
Part 1: Metrological and technical requirements

`sources/r060/2/`::
Part 2: Metrological controls and performance tests

`sources/r060/3/`::
Part 3: Test report format

`sources/r060/annex/`::
Annexes

`reference-docs/`::
Reference documents.

`_site/`::
(automatically generated after compilation) published documents.


== Prerequisites

- To render proper PDF/HTML you need to have the "`Futura PT *`" fonts
available to Metanorma. They are available in private Metanorma Fontist formulas repository,
which you would need to have access to.

== Shortcut: using pre-built Metanorma container image

This skips the need for some installation steps, but is likely to be slower
than the regular local installation approach and Metanorma version available
in the image may lag a few days behind the latest version. Requires:

- Podman or Docker.
- Your Github Personal Access Token, which you would need to provide the container.

Single-command Podman example that builds the site (tested in Zsh, Fish):

[source,sh]
----
podman run --cpus=4 --memory=6g -v "$(pwd)":/metanorma -w /metanorma -it metanorma/metanorma sh -c "fontist update && fontist repo setup metanorma 'https://<YOU_GH_PAT>@github.com/metanorma/fontist-formulas-private' && fontist repo update metanorma && fontist install 'Futura PT Book' && fontist install 'Futura PT Demi' && fontist install 'Futura PT Light' && metanorma site generate --agree-to-terms"
----

== Usage (general)

Requires Ruby 2.6+.

=== Installing Metanorma

See https://www.metanorma.org

=== Installing fonts

Adding the private Metanorma Fontist formula repository.

[source,sh]
----
fontist repo setup metanorma git@github.com:metanorma/fontist-formulas-private.git
# Or
# fontist repo setup metanorma https://github.com/metanorma/fontist-formulas-private
fontist repo update metanorma
----

Install the formula, otherwise Metanorma on the first run of the OIML flavor
will automatically install this.

[source,sh]
----
fontist install 'Futura PT Book'
fontist install 'Futura PT Demi'
fontist install 'Futura PT Light'
----

=== Building R-60 collection

The easy way if you install locally:

[source,sh]
----
git clone https://github.com/metanorma/mn-samples-oiml/
bundle
bundle exec metanorma sources/r060/collection.yaml
# => sources/r060/collection.{html,pdf,xml}
----

=== Building a single document

[source,sh]
----
bundle exec metanorma sources/r060/1/document.adoc
----

This command outputs the built document at:

* `sources/{document-dir}/document.{html,pdf,xml}`

=== Building the full site

[source,sh]
----
bundle exec metanorma site generate
----

This command creates `_site/`. The HTML entry point is at `_site/index.html`.
